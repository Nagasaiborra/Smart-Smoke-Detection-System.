About Smoke Monitor

System Framework Diagram

This IoT dashboard manages telemetry sent over high-speed networks. Standard sensor variables parsed by hardware nodes are formatted as CSV lines and pushed via serial link to a Raspberry Pi client. The Raspberry Pi broadcasts packets in real time over WebSockets on port 8765. Our HTML5 client establishes a direct WebSocket interface, rendering dials and logs instantly without server-side processing queues.

System Hardware Nodes

ESP32 Micro-controller

MCU

Handles analog pin sampling for sensor voltages and feeds formatted lines to the host serial interface at 115200 BAUD.

MQ2 Sensor Module

Sensor

Detects smoke concentration levels and outputs proportional voltages corresponding to gas density (measured in PPM).

DHT22 Sensor

Sensor

Measures ambient temperature (°C) and capacitive relative humidity (% RH) with digital single-bus protocols.

5G Evaluation Board

Link

Simulates sub-millisecond mobile transit, linking Raspberry Pi WebSocket broadcasts directly to remote network endpoints.

Software Libraries & Protocols

Python websockets

Backend

Runs as an async daemon, listening to COM / ACM serial ports and broadcasting CSV telemetry strings directly to clients.

Vanilla ES6+ JS

Frontend

Direct browser WebSocket API connects, auto-reconnects, processes strings, manages states, and handles settings configurations.

SCADA Console

Telemetry

Renders scrolling telemetry grids, packet frequency statistics, state filters, and alarm color codes dynamically using ES6 DOM pipelines.

Lucide Icons (CDN)

Assets

Generates vectors representing metrics and status dials dynamically using HTML data attributes.
